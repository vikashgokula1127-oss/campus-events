# Campus Events

A static college event-management website for GitHub Pages.

## Files
- index.html
- style.css
- script.js
- college-logo.jpg

## Important
This version uses browser localStorage. Events created on one browser/device are not automatically visible to other students.

For a real college-wide host system where the host creates events and every student sees them, connect the site to a backend/database such as Firebase or Supabase.
